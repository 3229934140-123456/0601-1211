📦接入发布演示（构建产物双路径）


      

        
        
        
      


      

        
当前演示页使用此方式。适合使用 Vite/Webpack 等现代打包工具的业务项目。

        
// package.json
{
  "dependencies": {
    "survey-sdk": "file:./dist"
  }
}

// 业务页面 app.ts
import { SurveySDK } from 'survey-sdk';

const sdk = SurveySDK.create(surveyConfig, {
  autoSave: true,
  submitUrl: '/api/survey/submit',
  renderConfig: { displayMode: 'all' }
});
sdk.setUser({ userId: 'EMP_001' });
sdk.mount('#survey-container');

sdk.on('submitSuccess', ({ result, summary }) => {
  console.log('厚摘要', summary.optionDistributions, summary.ratingOverview);
});

      


      

        
npm run build 后直接拿 dist/survey-sdk.umd.js，无需构建工具即可接入老系统。

        
<!-- 1. 引入 UMD 构建产物（npm run build 产出） -->
<script src="/dist/survey-sdk.umd.js"></script>

<!-- 2. 页面容器 -->
<div id="survey-container"></div>

<!-- 3. 初始化（全局 window.SurveySDK） -->
<script>
  const SurveySDK = window.SurveySDK;
  const sdk = SurveySDK.create(surveyConfig, {
    autoSave: true,
    autoSaveInterval: 15000,
    storageKeyPrefix: 'biz_survey'
  });
  sdk.setUser({ userId: 'EMP_12345', username: '李四' });
  sdk.mount('#survey-container');

  // 整页模式 + 检查必答题定位
  sdk.setDisplayMode('all');
  sdk.on('validateError', ({ invalidQuestionIds }) => {
    console.log('未答必答题', invalidQuestionIds);
  });
</script>

      


      

        

          
✅ 接入步骤（业务同事照着做即可）：

          
    
            
  1. 运行 npm run build，等待 dist 目录产出
    2. 
            
  2. 拷贝 dist 下所有文件到业务项目（survey-sdk.umd.js / index.d.ts 等）
    3. 
            
  3. 按上面"方式一"或"方式二"引入 SDK
    4. 
            
  4. 准备好 Survey 配置 JSON（至少含 meta + questions 数组）
    5. 
            
  5. 调用 SurveySDK.create() → setUser() → mount() 三步完成挂载
    6. 
            
  6. 监听 submitSuccess 事件，拿 result.submissionId 和 summary 做完成页
    7. 
          

          
💡 推荐：新业务用方式一 ESM 导入 + TS 类型提示；老系统用方式二 UMD 零构建接入。
